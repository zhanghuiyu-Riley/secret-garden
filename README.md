# 🌿 秘密花园 · Secret Garden

一座会呼吸的秘密花园。点击地面播种，看花在昼夜流转中抽茎、舒展、发光。

**单文件 · 零依赖 · 零构建** —— 打开 `index.html` 即可。

---

## 它能做什么

| 交互 | 效果 |
| --- | --- |
| **点击地面** | 播下一颗种子，2 秒内抽茎、长叶、开花 |
| **点击花朵** | 授粉，炸开一圈花粉光点 |
| **点击天空** | 撒下一把星尘 |
| **`C` 键** | 手动推进四分之一个昼夜 |
| **`R` 键** | 清空花园，重新开始 |

移动鼠标靠近花朵时，它们会朝你的方向轻轻倾身。

## 世界是活的

- **昼夜循环** —— 150 秒一昼夜。天空从深夜靛蓝，经晨曦的暖橘，走到正午的明蓝，再回到暮色。太阳与月亮沿同一道弧线东升西落，月亮上还有环形山。
- **五种花形** —— 雏菊、铃兰、蒲公英、玫瑰、星芒。每朵花由种子确定：`mulberry32(seed)` 决定它的品种、七套配色中的一套、茎高、花瓣数、弯曲度与摇曳相位。**同一种子永远长出同一朵花。**
- **萤火虫** —— 夜里苏醒，各自认领一朵花作为目标，慢悠悠地飘过去；天亮后逐渐蛰伏。
- **风** —— 两条不同频率的正弦叠加成阵风，同时吹动花茎与草叶。
- **夜光** —— 环境越暗，花朵的光晕越强，形成一种"花园在夜里自己发光"的错觉。

## 它记得你

花园会存进 `localStorage`，坐标以**画面比例**存储，所以换窗口尺寸、换设备都不会错位。下次打开，花开如故。

## 实现备注

纯 Canvas 2D，无任何依赖。约 700 行，结构大致是：

```
数学工具 / 颜色混合  →  世界状态  →  花(生成·生长·绘制)
                                  →  萤火虫 / 粒子 / 涟漪
                                  →  昼夜与天空  →  大地与山脊
                                  →  主循环  →  交互  →  存档
```

几个值得一提的点：

- **山脊参数只生成一次**（固定种子），`resize` 时复用，所以窗口缩放不会让山形跳动。
- **花朵逐帧按 `y` 排序**，后排先画，自然产生前后遮挡。
- **萤火虫用「认领目标」而非全局最近邻**，把每帧 O(n×m) 的搜索降成 O(m)。
- 所有数量都有上限（170 朵花 / 1400 粒子），狂点也不会拖垮帧率。

## 本地运行

```bash
# 直接打开
start index.html          # Windows
open  index.html          # macOS

# 或者起个本地服务
python -m http.server 8000
```

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save。
一分钟后访问 `https://<你的用户名>.github.io/secret-garden/`。
